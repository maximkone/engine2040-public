## What it is

A single-crate, pure rules core: seed + decks + decisions fully determine the game (`Rng` is SplitMix64, no clock, no IO), effects are data (`EffectSequence`, `EffectAmount`), an event log feeds history queries, and one function defines what each player may see. Its test suite is specification-shaped: one file per concern (cards, legality, resolution, triggers, targeting, turns, views, state_check, properties) plus a property file.
