## What it is

A three-crate engine for tabletop rounds run by an AI GM that cannot write outside the rules: crates/kernel (rules, canon, store, firewall), crates/round (journal, replay, property tests), crates/spook (host, AI loop, seat protocol). Its defining choice is that the journal is the game: one writer, a hash-chained append-only record, and an engine-guarantees doc that states each promise and names the feature file that tests it.
