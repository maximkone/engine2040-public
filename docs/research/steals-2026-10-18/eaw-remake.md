## Steals (ranked by value per hour)

1. **Cull by projected pixel size, not by distance** | eaw-remake@c1ea790a10ce:crates/alamo-render/src/lod.rs:16-33 (`LodSettings { enabled, min_model_px: 2.0, particle_min_px: 1.0 }`), :36-56 `cull_small_models`: project the bounding radius to pixels as `px = 2 * radius * px_per_unit / dist` (distance floored at 1e-3) and hide the node when `px < min_model_px`; particles below `particle_min_px` are never built | MIT | our file: `crates/render/src/draw.rs` (beside `pick_lod` hysteresis), `crates/render/src/crowd_impostor.rs` |
   Our LOD switches by distance, which is wrong twice: a far fighter is bigger on a wide FOV and smaller on a narrow one, and a small prop next to the camera gets a low mesh. One division gives a size rule that is resolution- and FOV-honest. The particle half is free: do not even build a puff that will cover one pixel. Kill: if the potato tier's distance buckets already land within one LOD level of the pixel rule at 1080p, keep the buckets and add the rule as a test only.

2. **A frame-spike note ring any module can write to** | eaw-remake@c1ea790a10ce:crates/alamo-render/src/frame_trace.rs:1-3 (`SP_FRAME_LOG=<ms>`: one-off main-thread work such as model builds, texture decodes, particle and animation parses leaves a note, and the battle view prints the notes of every frame over the limit; without the variable nothing is recorded), :10 `MAX_NOTES = 256` (oldest dropped), :19 `note(text: impl FnOnce() -> String)` (lazy), :31 `note_slow(what, took, min)`, :38 `take()` | MIT | our file: `crates/perf` (a new note channel), printed by the arena printer beside the pass ms |
   A pass timer says *where* the frame time went. It cannot say why frame 412 cost 30 ms when the pass times are normal: that was an asset decode or a first-time pipeline build on the main thread. A global note ring, off unless an env var is set, lets any module (cook, shader, load) name itself at the moment it runs slow, and the frame printer shows the notes for the slow frames. Cost is zero when off. Kill: if the arena already prints the same facts and the note would duplicate a pass row, keep it dev-only and behind the existing profiler switch.
