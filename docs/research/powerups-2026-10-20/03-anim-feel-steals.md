# 03 — Animation and feel: which GitHub repos fill the gaps

Lane answer: most of the animation mechanics already live in this tree, so the donor hunt is
narrow. `git grep` on `crates/` shows `crates/anim/src/motion_match.rs` (LM1, motion matching v2),
`crates/anim/src/springs.rs` (AM11, fixed-point spring bones), `crates/anim/src/inertial.rs` plus
`crates/anim/src/inertialize.rs` (LF9 inertialized switches, AM24 `AngularLimiter`),
`crates/anim/src/ik.rs`, `crates/anim/src/fbik.rs`, `crates/anim/src/feet.rs` (two-bone, FABRIK, foot
lock), `crates/anim/src/additive.rs` plus `crates/anim/src/hit_react.rs` (AM15 spine, hit react),
`crates/anim/src/pack.rs` (`PACK_VERSION_ROT`, smallest-three quaternion lanes = the first half of
C14), `crates/anim/src/edit.rs` (trim, retime, cleanup, strip, mirror), `crates/anim/src/lipsync.rs`
plus `crates/anim/src/viseme.rs`, `crates/anim/src/lod.rs` plus `crates/anim/src/crowd_scale.rs`,
`crates/anim/src/graph.rs` plus `crates/anim/src/state_machine.rs` and the JSON graph door in
`crates/endpoint/src/packs/anim.rs` (`anim.graph.set|get|undo`, `anim.preview`). Those areas are not
gaps, so no donor is written for them. What is missing is code that does not exist at all: a BVH
motion intake (NS19), weapon and shield sockets on hand bones (EG40, LF12), rotation-additive hit
flinch layers (AM23, second half of C14), a live phoneme-to-viseme curve source (LAI3), JSON graph
data for the state machine and blend tree (EG18b), and two research-only tails (crowd LOD sharing,
live pose tracking for NS8). Ten donors below, all read live on 2026-10-20.

## Rejections

- Motion matching: `crates/anim/src/motion_match.rs` exists (LM1 ticked, v2 with trajectory prediction and a feature schema). Not a gap, no donor written.
- Spring bones and secondary motion: `crates/anim/src/springs.rs` exists (AM11, fixed-point spring bones, Q12). Not a gap.
- Spring arm: `crates/game/src/camera_rig.rs:759` already carries a PORT line for the Godot spring arm; Godot is on the mined list. No new donor.
- Inertialization and inertial blending: `crates/anim/src/inertial.rs` landed (LF9 ticked) and `crates/anim/src/inertialize.rs` holds the `AngularLimiter` (AM24). Not a gap.
- Angular-speed limiter: the limiter exists; the AM24 residual is root and translation motion plus frame cadence, which is our own root-motion code. No donor found that is not the mined ozz or the row's own Godot cite.
- Two-bone IK, FABRIK and foot planting: `crates/anim/src/ik.rs`, `crates/anim/src/fbik.rs` (FABRIK with a two-hand grip mode) and `crates/anim/src/feet.rs` exist. LF12's only open half is the socket, which is row 3.
- Rotation-additive flinch: `crates/anim/src/additive.rs` and `crates/anim/src/hit_react.rs` exist but the flinch writes identity rotations, so rows 2 and 8 are the donors for it.
- Clip trim, retime, mirror and cleanup as callable operations: `crates/anim/src/edit.rs` already has `trim`, `retime`, `cleanup`, `strip` and `mirror` over `QClip`/`QTrack`. `git grep "edit::" crates/` returns only `crates/anim/src/state_machine.rs:31` (a different module), so the verbs have no caller and the open work is the door verbs, which is our own code. No donor needed; the three.js `subclip` in the same file as row 2 is a reading, not a new find.
- Quaternion packed clip lanes and clip compression: `crates/anim/src/pack.rs` already stores smallest-three u16 quaternion lanes (`PACK_VERSION_ROT`), and `crates/assets/src/anim_compress.rs` exists. C14's first half is done.
- Procedural hit reactions and stagger: `crates/anim/src/hit_react.rs` and `crates/combat/src/depth.rs` (poise) exist; only the rotation delta is missing, which is row 2.
- Crowd animation LOD and animation sharing: `crates/anim/src/lod.rs` (tier table, 8 nearest at full rate) and `crates/anim/src/crowd_scale.rs` (1000-agent tape) exist. AM13's missing part is the 64-fighter timing receipt, a measurement, not a donor. Row 9 is the only sharing idea found.
- Facial and lip sync: `crates/anim/src/lipsync.rs` and `crates/anim/src/viseme.rs` exist as an offline phoneme bake. LAI3 needs a live curve source, which is rows 4 and 5.
- BVH motion intake: nothing in `crates/` reads BVH (`git grep -i bvh crates/` returns only the ray-tracing BVH in `crates/audio/src/trace.rs` and the xatlas vendor). Row 1 is the gap.
- Gait and locomotion state machines: `crates/anim/src/locomotion.rs` and `crates/anim/src/state_machine.rs` exist; row 6 only shows the JSON shape.
- Anim graph node editors in data: `crates/anim/src/graph.rs` plus the JSON door `crates/endpoint/src/packs/anim.rs` (`anim.graph.set|get|undo`) exist. Row 6 is the donor shape for EG18b, not a new system.
- BX5 injured locomotion (hop, crawl, fall, one-arm guard): no MIT-class code donor found. The missing part is clip content plus our own `crates/anim/src/injured.rs` masks. CMU-style mocap data was not proposed: AGENTS cuts mocap bytes in git.
- EG42 baked per-move hit tracks: no donor needed. `crates/anim/src/loco_bake.rs` already bakes integer-mm rows and `crates/anim/src/hit_track.rs` exists.
- LF9, LF13, LF14, EG18b, EG19c: all our own code in this tree (`inertial.rs`, `fbik.rs` look-at, `trails.rs`, `state_machine.rs`, `fighter_look.rs`). No external donor needed.
- orangeduck/Motion-Matching: already cited by board rows LF12 and LF13. Not a new find.
- Unity-Technologies/Animation-Instancing: Unity is on the mined list and the repo carries its own licence. Rejected.
- DragonBones (slots and attachments) and amethyst/lumberjack: the repos returned 404 on the GitHub API today, so no file could be read. No row written.
- crowdbake has no LICENSE file, so its code is off limits; only the README ideas are read.
