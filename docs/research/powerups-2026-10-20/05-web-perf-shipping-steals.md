# G5: web, perf, assets, shipping — which GitHub repos close these gaps (2026-10-20)

Lane G5. Read-only lane: one file, nothing committed. All donor files and licences were read
live on 2026-10-20 (raw source and the GitHub contents API), and the tree was grepped before
anything was called missing.

**Answer.** Most of this lane's gaps are already closed in our own tree, so the hunt had to go
past the obvious names. Grep proof (2026-10-20): the strict WebGPU CI leg exists
(`crates/render/src/backend.rs:437-461` reads `E2040_STRICT_WEBGPU`, `.github/workflows/ci.yml:111`
sets it, `:461` adds `wgpu::InstanceFlags::STRICT_WEBGPU_COMPLIANCE`); the browser netcode exists
(`crates/net/src/browser/wt.rs`, `crates/net/src/browser/ws.rs`, `crates/net/src/bin/net_serve.rs`,
a headless-Chrome duel in the net CI job); cross-origin isolation exists
(`crates/web/coi-serviceworker.js`, `crates/web/src/shell.rs:76-79` reads
`window.crossOriginIsolated`); the wasm size tools are in the build
(`.github/workflows/web-build.yml:65-80` installs binaryen `wasm-opt` and `twiggy`); the quality
ladder exists (`crates/render/src/tier.rs`, `crates/web/src/tier_view.rs`, the `WEB_CUT_ORDER`
test); the potato gate exists (`tools/potato-check.mjs`). What is still missing, and has a donor
I read today: the **AudioWorklet sink** for gap A5 (the page still uses the deprecated
`ScriptProcessorNode`, `crates/web/src/browser.rs:26,52`), the **Basis/KTX2 transcode at load**
for QW5, the **draw-call receipt** for QW10, **one Perfetto-readable trace file** for gap 13,
and three **measurement** donors for the build and ship rows (crate-split cost, receipt
snapshots, PGO). The remaining hunted areas have no new donor: the crash row already names
EmbarkStudios crash-handling, GS35 already names Bevy, and the browser-transport space was
mined in the 2026-10-18 wave (renet2, naia, lightyear, matchbox).

## Rejections

Checked and dropped, one line each, so nobody re-mines them.

- **A4, strict WebGPU CI leg: no donor needed, already in the tree.** `crates/render/src/backend.rs:437-461` reads `E2040_STRICT_WEBGPU` and adds `InstanceFlags::STRICT_WEBGPU_COMPLIANCE`; `.github/workflows/ci.yml:111` sets the variable for the test matrix. The only thing missing is a runner with a GPU adapter (the leg skips there), which is an infra fact, not a steal.
- **Browser netcode transport (WEB9 / WEB12): already built and already mined.** `crates/net/src/browser/wt.rs` and `ws.rs` (the WebTransport API declared by hand because web-sys gates it), `crates/net/src/bin/net_serve.rs` (WebSocket plus optional WebTransport with a pinned cert) and a headless-Chrome duel in the net CI job. `moq-dev/web-transport` is named in the plan; `UkoeHB/renet2`, `naia-lib/naia`, `cBournhonesque/lightyear` and `matchbox` were all read in `docs/research/steals-2026-10-18/03-net-web-audio.md`. No new donor.
- **Wasm size cuts: already in the build.** `.github/workflows/web-build.yml:65-80` installs binaryen `wasm-opt` and `twiggy`; `tools/web-budget.mjs:137` prints the twiggy lines; `tools/wasm-info.mjs` compares the two sizes. `razrfalcon/cargo-bloat` (MIT) overlaps twiggy and adds nothing.
- **`rustwasm/wasm-snip`: REJECT, archived.** The repo is marked archived and it needs nightly plus `wasm-tools`; the size win does not pay for a nightly toolchain on the web build.
- **WEB14 cross-origin isolation: already in the tree, donor already credited.** `crates/web/coi-serviceworker.js` (it names `gzuidhof/coi-serviceworker`, MIT, in its own header). What WEB14 still lacks is the atomics wasm build, which row 1 needs (cpal's AudioWorklet host says "Requires atomics support").
- **Web audio donor hunt: `RustAudio/cpal`'s legacy webaudio host is not the answer.** `src/host/webaudio.rs` is the old `ScriptProcessorNode` path; the new `src/host/audioworklet.rs` is the one we want (row 1). `whoisryosuke/clawdio` and `piutranq/wasm-audioworklet-example` (Unlicense) were also read: they show the same Rust-exports-a-buffer / JS-worklet-calls-it pattern but are tiny; cpal is the maintained one.
- **Crash and device-lost reporting (PF28): the row already names the donor.** The row text names "crash-handler and minidumper (EmbarkStudios, MIT or Apache-2.0)", and `crates/game/src/crash.rs:729-733` already carries the PORT note for `EmbarkStudios/crash-handling@e7d5067`. The device-lost half is wgpu's own `Device::lost` callback, an API, not a donor.
- **Potato tier (G9) and the quality ladder (GS35, QT5): in the tree, donor already named.** `crates/render/src/tier.rs`, `crates/web/src/tier_view.rs`, `tools/potato-check.mjs`, and the GS10 tier rules landed; GS35 already names Bevy's `GpuPreprocessingSupport` shape. The one thing no repo supplies is a fixed ordered cut list: propose a new row (`WEB_LADDER_ORDER`) instead of a steal.
- **Content streaming (WEB6, QW4): the seam is already in the tree.** `crates/assets/src/asset_source.rs` (the `AssetSource` seam) and `crates/assets/src/bin/arena_bundle.rs` (the `E2BUNDLE` cook with the byte budget) exist; the gap is ordering and a progress bar. `zeux/meshoptimizer` and `gltfpack` are already mined for the LOD side (VR4, QW6).
- **`sccache`, `mold`, `cargo-nextest`, `Swatinem/rust-cache`: already in CI.** `.github/workflows/ci.yml:109` sets the mold linker flag, `:118` uses `sccache-action@v0.0.11`, `:121` uses `Swatinem/rust-cache@v2`, `:125-130` installs and runs `cargo-nextest`, and `sccache-action` appears in six jobs. `cargo-hakari` is half in already (`crates/workspace-hack`, OPT36 per OPT8's progress note).
- **Perf overlay: `EmbarkStudios/puffin` is already named in the PF27 row text** (MIT OR Apache-2.0, `LICENSE-MIT` and `LICENSE-APACHE` read live). Not a new find; row 4 covers the missing part (a trace file).
- **Bevy, `ggrs`, `meshoptimizer`, `gltfpack`, `glTF-Transform`, Godot, Unreal, Unity, O3DE, Flax, Stride, Filament, `wgpu` STRICT_WEBGPU_COMPLIANCE:** named in `RULES.md` as already mined, not re-read.
