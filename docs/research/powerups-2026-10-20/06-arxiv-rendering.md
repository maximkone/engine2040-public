# 06 - arXiv rendering wave (2026-10-20)

## Answer

The renderer already owns the classic forward stack: TAA with a 3x3 box clamp and a velocity rejection
(`crates/render/src/post/taa.rs`, `crates/render/src/shaders/post/taa_compute.wgsl`), Halton-2/3 jitter
(`crates/render/src/post_jitter_motion.rs`), a half-res GTAO (`crates/render/src/gtao.rs`), cascaded sun
shadows plus a 250-torch cluster (`crates/render/src/shadow_cluster.rs`, `crates/render/src/shadow_cascade.rs`),
a CPU-baked SH irradiance path (`crates/render/src/ibl.rs`, `crates/render/src/baked_gi.rs`), an FSR-shaped
spatial upscale (`crates/render/src/post/upscale.rs`), MSAA (`crates/render/src/present/gpu_present/msaa.rs`),
a GPU frustum cull slice (`crates/render/src/gpu_cull.rs`), a height fog and contact shadow pass
(`crates/render/src/fog.rs`), a hue-keeping display tonemap plus one fixed 4x4 dither
(`crates/render/src/shaders/tonemap.wgsl`, `crates/render/src/shaders/blit.wgsl`) and one
integer dynamic-resolution governor (`crates/render/src/dynres_gov.rs`). The arXiv papers that move it
forward are therefore not "another TAA" or "another tonemap". They are the four missing pieces the tree
provably does not have (`git grep` on `crates/` returns zero hits for `froxel`, `hzb`, `depth_pyramid`,
`svgf`, `reblur`, `blue_noise`, `stbn`, `variance_clip`, `ycocg`): a **runtime probe-grid GI** (RT8),
a **spatial + temporal denoiser** (RT6), a **volumetric froxel** (VX1/VX17), and a **real-time path
tracer** (RT7). On top of that sit four cheap, well-scoped upgrades that need no new crate: filter-adapted
sampling noise instead of Halton, an occlusion-point reuse estimator for ray-traced AO and shadow, a
JPEG variable-rate texture path for the web bundle, and a perceptual colour-difference space for the
look gate. Everything below was read on 2026-10-20. The arXiv export API rate-limited (HTTP 429) after
the first three queries, so the remaining entries were read from the `arxiv.org/abs/...` pages and the
`arxiv.org/list/cs.GR/<YYYY-MM>` monthly listings (both answered 200 all day); every version and date
below comes from the live `Submission history` block on the abs page. Donors named in
`docs/research/LADDER.md` were skipped (checked: `2112.09629` STBN and `2608.27888` NTC are already
carded, so blue-noise dither and NTC are **not** re-proposed here).
