== 1. WE HAVE ==
1. Live frame (live.rs:209-282): one encoder = sun depth pass + forward + sky + blit, no readback. The sun pass redraws EVERY item each frame into 256x256 D32 over 32 m = 12.5 cm texels
   and nothing samples it (submit.rs:461-478, sun_shadow.rs:224-231, twin_shadow.rs:57,65). `fs` only dims by view distance (forward.wgsl:401-409): the window has no real sun shadow. Plan: RL27 (render-look.md:366).
2. Draw data: DrawItem = mesh + material + texture, NO transform (present.rs:375-387); forward `vs` takes world-space vertices (forward.wgsl:205-214). 4 wgpu calls per item forward, 3 in the sun pass,
   cap 256 items (present.rs:28, draw.rs:22), material ring 256 B stride for 32 B of data (submit.rs:879-887). No instance step, indirect draw, bundle or override in render/src (grep). Plan: RL32 (SPRINT-20:298), CQ19 (:262).
3. draw.rs has sphere cull, hysteresis LOD on distance bands only (:354-365) and instanced squads (:592), but no caller except tests/it/lod.rs:9 and lib.rs:107. The 1,000-agent "under 1 ms p95" test is ignored
   and no number was ever posted (:1382-1412). Plan: GS18/GS18b sphere cull (SPRINT-18:198-214); VG1/VG4/VG8 frozen Tier C (SPRINT-12:104-274); render-look.md:101 cuts meshlets without a profile.
4. State: PrimitiveState::default() = no back-face cull (submit.rs:1157); glTF doubleSided is only noted (material/gltf_import.rs:628); standard-Z Depth32Float, clear 1.0 (v1.rs:399-404, submit.rs:493,1161).
   A depth-only vertex entry exists (forward.wgsl:242) but no prepass runs.
5. Targets at 1080p: HDR 16.6 + out 8.3 + depth 8.3 + fog 8.3 + ao 8.3 + id 8.3 = 58 MB (submit.rs:125-196). Fog, ao, id and out (33 MB) are neutral or unused in the live frame, yet blit.wgsl:48-49
   still reads fog and ao for every pixel (16.6 MB per frame, computed).
6. Pacing: ControlFlow::Poll + redraw (arena.rs:1383-1385); swapchain mode = caps.present_modes[0], latency 2 (presenter.rs:643,646). On DX12 that list is [Mailbox, Fifo, Immediate] (wgpu-hal dx12/adapter.rs:1316-1319)
   and Mailbox presents with interval 0 (dx12/mod.rs:1834-1836): the window is uncapped. On Vulkan [0] is the driver's order. Plan: OPT18 (SPRINT-13:74) waits on WIN1, PF2.
7. Device asks only TIMESTAMP_QUERY (presenter.rs:547), default limits; the GPU timer has 4 queries = forward and blit (timing.rs:19-20). Plan: OPT16 ladder waits on VG1 (SPRINT-13:62); GS9/GS10 (potato.md:84-85).
8. Graph: executor.rs plan_aliases shares slots by BYTE SIZE only (:79-105). wgpu 30.0.1 has no placed or aliased resources (no "placed"/"alias" API in wgpu/src/api), so the "~25 MB after aliasing"
   (render-look.md:175-176) cannot be built as planned. Graph and executor are not in the live frame (potato.md:11).
9. Mesh cache holds 512 meshes, insertion-order eviction (present.rs:29-30), 2 buffers per mesh (presenter.rs:717-732): a 600-chunk collapse evicts its own chunks. Particle pool is CPU-stepped, cap 4,096/8,192
   (particles_gpu.rs:27-29). uploads.rs StagingBelt (lib.rs:90) and render stream.rs (lib.rs:97) are models with no caller (grep "uploads::" empty).
10. wgpu 30.0.1 on DX12 exposes MULTI_DRAW_INDIRECT_COUNT, INDIRECT_FIRST_INSTANCE, TIMESTAMP_QUERY_INSIDE_PASSES (dx12/adapter.rs:463-472). TEXTURE_BINDING_ARRAY needs SM5.1 + Resource Binding Tier 3
    (:504-513); BUFFER_BINDING_ARRAY is Vulkan only (features.rs:803); PIPELINE_CACHE Vulkan only (:1165); SHADER_DRAW_INDEX not on DX12 (:1436-1446); mesh shaders need passthrough shaders off Vulkan (:1285).
    Override constants work (api/common_pipeline.rs:17). Bundles have draw_indexed_indirect, no multi-draw (api/render_bundle_encoder.rs:201). Multi-draw without the count feature may be a CPU loop (features.rs:870-874).
11. DX12 TRAP, read in source: the *_indirect_count calls use prepare_draw(0,0) and the plain signatures (wgpu-hal dx12/command.rs:1470-1509), so first_instance does not reach @builtin(instance_index) there;
    the non-count indirect path uses special signatures (:1376-1453). wgpu#2471 closed 2025-04-15 (PR #7535) for the non-count path. Bevy main still caps DX12 at preprocess-only for this reason.
    Rule for us: per-instance data goes in an instance-step vertex buffer (the input assembler adds the start instance), never instance_index into storage on count draws.
12. Back end is Auto = all (backend.rs:202,423), so Vulkan or DX12 can win on the same GPU; every steal below must run on both and on the potato (Intel UHD, DX12 Tier 3, no count draws assumed).

== 5. NOT WORTH IT (checked, rejected for this game) ==
1. Meshlet virtual geometry (VG3/VG13/VG14): Bevy's own docs need TEXTURE_INT64_ATOMIC + SHADER_INT64 + SUBGROUP + IMMEDIATES and run on Vulkan and Metal only (bevy_pbr meshlet/mod.rs), its 0.14 write-up says opaque and no animation, and our kit is 60k tris (render-look.md:224). Fighters and crowd animate. Keep frozen.
2. Two-phase Hi-Z occlusion (niagara, Bevy): Bevy's docs say off by default, enable only if measured faster; our camera sits in a bowl whose stands face the pit, so little is hidden. Revisit for district/siege (UC rows) with a profile.
3. Bindless TEXTURE_BINDING_ARRAY: native-only, DX12 needs Resource Binding Tier 3 (adapter.rs:504-513), BUFFER_BINDING_ARRAY is Vulkan-only; the arena has ~12 textures, sorted bins switch bind groups a dozen times. A texture_2d_array layer per crowd variant works on every tier.
4. Mesh shaders, The Forge visibility buffer 2.0, Blade: wgpu mesh shaders need passthrough shaders off Vulkan (features.rs:1285); Forge release 1.57 calls TVB 2.0 a prototype and posts no ms (Apache-2.0, cd5046893); Blade has its own HAL, not wgpu, and no render graph or bindless in its README (MIT). Forward + prepass covers our overdraw.
5. Reverse-Z: Depth32Float standard-Z with near 0.1 m has ~1.5 mm steps at 50 m and ~6 mm at 100 m (computed), well under decal offsets; it touches about 8 depth-compare sites and the CPU twin oracles. Do it only with a Hi-Z or fog-depth need.
6. Compute skinning and async compute: 2-16 skinned fighters through 4-5 passes is under 100k vertices; wgpu 30 gives one Queue per device. Only the RT BLAS refit (accel.rs) needs skinned vertices in a buffer, and that is Tier C.
