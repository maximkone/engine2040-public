The sun depth map (256x256 ortho over a 32 m pit, twin_shadow.rs:57,65) is drawn each frame (submit.rs:464-478) and the code says "Nothing samples it yet" (submit.rs:463). The twin shader is a one-texel hard compare (twin_shadow.rs:592-597). No GPU PCF/PCSS (CPU 4-tap only, v1_ibl_shadow.rs:312). The depth pass is position-only, no skinning (twin_shadow.rs:535-544).

Plan: RL27 cascaded shadow maps, Tier B, no needs (render-look.md:366).
5. The pass named "contact-shadow" is contact AO (fog.rs:26-34 resource contact_ao, 4 slices 2 taps fog.rs:65-67), no march toward the sun. The depth target cannot be sampled: usage is RENDER_ATTACHMENT|COPY_SRC only (submit.rs:154-156).
6. TAA is three copies: CPU oracle + compute + a fragment twin (post.rs:391-448, shaders/post/taa_compute.wgsl:36-63, shaders/post/taa_resolve.wgsl:7-26) plus test-only v1_temporal.rs:1-9. All do bilinear history, RGB 3x3 min/max clamp, and drop history entirely past 32 px of motion (post.rs:348-366). No depth dilation, no variance clip, no Catmull-Rom, no luma weighting, no locks. Halton jitter exists (post.rs:176-228) but the live frame never jitters, and DrawItem has no previous transform (present.rs:375-387): there are no motion vectors on the GPU path. Gates: GHOST_MAX_TRAIL 0.25, SHIMMER_MAX_VAR 0.01 (post.rs:61,63).
7. Upscale/AA ladder: FSR1 EASU+RCAS are CPU code (post.rs:561-870, PORT marker :573); the WGSL file is 11 lines of helpers (post/fsr_easu_rcas.wgsl); live TAAU is a frozen bilinear (post.rs:507). 9. Exposure: CPU log-luma histogram, 64 bins, trim 10..95 percent, 3 EV/s slew (post.rs:1373-1720). Plan row RL18 open (render-look.md:358). On the live GPU frame it would need a readback.
10. Grade: contrast around linear 0.18 applied AFTER the tonemap, saturation, lift, gain (post.rs:1753-1771); no LUT. Grep of crates/render/src finds no vignette, chromatic aberration, film grain, dither, depth of field, motion blur or sharpen on the GPU.

== 5. Not worth it ==
- Full virtual shadow maps (Unreal style): none found in Bevy, Godot, Wicked or Flax; open code is UnityVSM (no license seen) and Blender EEVEE-Next (GPL, idea only). One sun in a bounded pit gets 0.4 cm and 1.6 cm texels from two fixed maps; page tables and feedback cost more than they save.
- Intel XeSS: the repo license is the Intel Simplified Software License, binary only, no source (LICENSE.txt read). FSR4 and DLSS are closed ML too. FSR3.1 temporal is MIT and open, so we use that shape through the WGSL port in pmndrs/upscaler.
- LUT tonemappers (Tony McMapface 48^3, Bevy AgX 32^3, Blender Filmic 64^3): each needs a binary 3D texture asset and upload path; analytic Neutral and AgX do the same job with zero files.
- Filtered soft shadows by moments (Filament EVSM/EVSSM, read in surface_shadowing.fs): light bleeding, four float moments and blur passes; PCF + PCSS under TAA is simpler and reads better on thin blades.
- Convolution (FFT) bloom and anamorphic flares: cost, no gain on a sand arena; dual-filter is enough.
- Depth of field and heavy motion blur on the gameplay camera: kills blade readability; kept for hero shots only (rank 13, rank 8 cheap variant).
