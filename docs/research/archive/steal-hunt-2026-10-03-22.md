## HOW THEY HANDLE it (mechanism notes)

- Roomer (paper, ideas-only): layouts encoded as `RoState`; `RoReview` binds measured violations to IMPLICATED OBJECTS (sparse, object-grounded — not scene-level). A geometry-conditioned VLM planner proposes a structured LOCAL edit; a DETERMINISTIC solver validates it and generates a finite candidate set when needed. Each candidate commits ONLY if full-scene verification confirms: target resolved + no new hard violations + protected constraints unbroken. Training: Roomer-CC controlled-corruption dataset (faulty layout + object-grounded violation evidence + known-feasible inverse StatePatch). Eval: Roomer-Eval — distributional quality + physical validity + practical USABILITY (existing benchmarks rarely assess whether valid layouts are usable). Result claimed: repairs residual violations, preserves valid regions, transfers across external generators. What they cut: no full-scene re-synthesis (local repair only), planner proposes / solver disposes (deterministic gate, never the model, beside our SP35 parity shape).
- Infinigen solver (BSD-3, PORT anchor): `SimulatedAnnealingSolver` (`annealing.py:34-46`) — `eval_memo` cache (`:65`) + `evict_memo_for_move` invalidates ONLY affected constraint-graph parts (`:209-210`); Metropolis acceptance (`:223-238`); `move.revert(state)` on reject (`:215`). Two phases: room layout then iterative object placement (`solve.py:58-86`). Moves: discrete Addition (spawn from `AssetFactory` on valid parent surfaces, `moves/addition.py:18-50`) + Deletion (drop high-violation contributors) + continuous Translation/Rotation restricted by `dof_matrix_translation` / `dof_rotation_axis` (`state_def.py:55-56`) with `restriction_matrix` projecting 3D motion onto support planes (`dof.py:27-38`, `check_init_valid :109-116`). Validity: `any_touching` / `min_dist` via trimesh+python-fcl (`trimesh_geometry.py:140-213`); `stable_against` triple rule — surface-normal parallelism (`stability.py:120-123`) + footprint containment via 2D polygon intersection (`:139-151`) + distance margin (`:170-177`). Donor proof: `tests/solver/test_stable_against.py` (sighted in file map + root `tests/` listing).
