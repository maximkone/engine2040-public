## HOW THEY HANDLE it (mechanism notes)

- godotshaders performant-SSS (MIT): SSS is a BAKED MASK + BACKLIT TRANSMISSION term, not a second BRDF. Blender-baked `subsurface_scattering_map` (thickness proxy) + `light()` adds `SPECULAR_LIGHT += max(abs(dot(-NORMAL, LIGHT)), 0) * LIGHT_COLOR/PI * ALBEDO * sss_map^2 * factor`. Note `abs()`: light behind the surface (ear-backlit case) still bleeds - that is the money term. Standard Burley + Schlick-GGX replica rides beside it untouched. Cost is one texture fetch + a few ALU in the light loop; works Forward+/Mobile/Compatibility (their claim).
- Nkentseu skin.frag.vk.glsl (PROPRIETARY, ideas-only): wrap-diffuse `wrapNdL = max(dot(N,L)+subsurface,0)/(1+subsurface)` + `sssOut += subsurfaceColor * albedo * rad * wrapNdL * subsurface`, weak roughness-modulated dielectric spec (shin 8..128, F0 0.04), NaN/Inf sanitize + HDR clamp 64. Corroborates the two-term shape (wrap for front, transmission for back) independently.
- Delyc (UNVERIFIED, ideas-only): reference-grade two-layer SSS random walk (Chiang-2016 style, per-channel free-flight, dielectric Fresnel exit with TIR, GGX + Kulla-Conty/Turquin multiscatter LUT, AOV-guided OIDN in linear pre-tonemap) + dedicated eye material (diffuse iris/sclera + tight dielectric highlight, NO subsurface) + mm scaling + sRGB-decode discipline. Zero learned weights in the stack (deps: taichi/numpy/imageio/oidn) - the non-AI baseline pole. Offline CUDA path tracer: never in-frame, reference-leg only.
- Outside-engines donor: Delyc Taichi path tracer (research renderer, not a game engine) + SIGGRAPH 2026 Advances course (talks). Non-AI baseline: analytic wrap + brute-force random-walk physics, no learning anywhere in either donor.
