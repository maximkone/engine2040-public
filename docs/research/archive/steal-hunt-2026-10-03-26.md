## HOW THEY HANDLE it (mechanism notes)

- SSR raymarch (salivity GLSL pair, fetched live 2026-10-03, UNVERIFIED blog ideas-only, zero bytes): view-space ray from `reflect(viewDir, N)` off the G-buffer normal → linear march in VIEW space, project each step to UV → depth test is NOT `rayDepth > sceneDepth` alone (buffer has no back-faces, objects read infinitely thick) but a thickness band `sceneDepth <= rayDepth <= sceneDepth + tau` → binary-search refine 8 steps between last-miss and first-hit → three fades multiply the sample: screen-edge fade (→ fallback env), ray-direction fade (R·V≈1 means no data), max-distance fade (no popping). Data shape is G-buffer + linear depth + one env fallback; no BVH, no ray queries, no history buffer in this variant (maorachow's HiZ variant adds mip-march as the A/B candidate).
- Progressive NEE+MIS reference (kody-w WebGPU page description + Piotrekstel writeup, search-metadata read live 2026-10-03, UNVERIFIED ideas-only, zero bytes): progressive compute accumulation with NEE + MIS on every bounce, GGX VNDF sampling, rough dielectrics, BVH meshes, A-Trous on the preview only; test battery is Cornell Box + caustics + furnace test. The non-AI pole: closed-form estimators, zero weights — the learned counterpole (RL adaptive sampling 2310.03507, kernel prediction 2202.05977 per hunt-2 R9) is explicitly NOT taken.
- Occluder-domain reuse (arXiv 2607.23122v1, abstract read live 2026-10-03, ideas-only, never bytes): AO and area-light shadows rewritten as occluder-domain integrals, neighbours combined with MIS; UNBIASED estimators prove convergence to the transformed integral, BIASED variants (local first-hit occluder consistency) are the real-time shape — and for shadows the occluder assumption matches local geometry better than light-sample reuse. Transfers as: reference carries the unbiased estimator (convergence proof), runtime later carries the biased variant; the unbiased-vs-biased PAIR is the discipline, not one kernel.
- What-broke (failure data, no live issues at cap): SSR article's own artifact list — off-screen rays, back-facing data absence, infinite-thickness false hits, edge popping (each with its named fade); RT13's standing threat — a reference where NEE-off does NOT score worse is rejected, i.e. the reference must be constructed so the ablation is load-bearing.
