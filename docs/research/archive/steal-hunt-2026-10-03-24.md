## HOW THEY HANDLE it (mechanism notes)

- Gizmo `fracture.rs` (MIT/Apache-2.0, PORT anchor): input is half-extents ONLY — every bounded collider's local box feeds `voronoi_shatter`, so a sphere breaks like its cube (`Breakable` excludes shapes, geometry stays in the parent local frame, debris shares the parent transform and differs only in mass props). Seeds from `StdRng::seed_from_u64(seed)`; cells = half-space intersections of 6 box planes + per-other-seed bisectors via plane-triple intersections; cells with <4 corners or no triangles DROPPED (count is an upper bound, never a promise). Mass props via `compute_convex_mass_props`: signed-tetrahedron decomposition, COM = volume-weighted centroid mean (vertex-mean fallback only when |signed volume| < 1e-8), volume = |sum| floored at 0.001 so mass-split never divides by zero. Guards: degenerate axes floored to 1e-3 (rand 0.10 empty-range panic fires in release too), `MAX_EXPLOSION_DV = 50.0` clamps `force/mass` dv, coincident seeds (<0.001) skipped. Cost section is explicit: per-cell plane-triple work climbs steeply — LOAD-TIME/`PreFracturedCache` routine, never per-frame. Determinism section is explicit: same `(extents, num_pieces, seed)` = same chunks, same-platform only, replay/rollback-safe; cross-platform/cross-version layouts NOT promised. Non-AI baseline inside: zero learned weights, pure planes + seeded RNG.
- oxiphysics `fracture_rigid.rs` (Apache-2.0, PORT anchor): `BreakableJoint` with THREE thresholds (tensile/shear/torsional) + `fracture_energy * area` released energy; `apply_force` decomposes force onto the joint axis (tensile = axial projection, shear = perpendicular, torsion = axial moment) and classifies the break mode (`BrokenTensile/Shear/Torsional`); sub-threshold hits ACCUMULATE damage Miner's-style (`sqrt(dt²+ds²+dtor²)*0.01`, break at 1.0) instead of our change-nothing; `FragmentSystem` + `CrackPropagation` (arrest) + `DebrisSimulation` (secondary impacts) + `ExplosionModel` (Gurney) surround it; `[f64; 3]` arrays, no linalg crate. What they cut: f64 math stays donor-side (ours is f32/integer-mm — adapt shapes, never the floats).
- Outside-games corroboration: ASCE Voronoi-DEM blast model (Voronoi elements = microcracks, pre-split bonded blocks) + MDPI quarry studies (fragmentation predicts excavation efficiency) — the pre-split + bonded-block + fragment-count discipline (50-150 interactive debris per the Medium piece) is industry-wide, not game-specific. arXiv DeepFracture 2310.13344 (generative brittle fracture): learned weights = negative result for our tick, kept as ideas-only shelf.
