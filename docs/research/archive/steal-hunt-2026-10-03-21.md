## HOW THEY HANDLE it (mechanism notes)

- OVSG framework (CoRL'23, UNVERIFIED ideas-only): grounding is RANKED RETRIEVAL + CONTEXT, never name match. OVIR-3D backbone fuses text-aligned 2D region proposals into 3D (multi-view fusion, real-time, no 3D training) and returns a RANKED SET of segments per language query by feature similarity; OVSG adds the context half — the query's related entities ("on a kitchen table", "on which someone is sitting") disambiguate among same-category candidates. Entities grounded: object instances, agents, AND regions. Evaluated on ScanNet + DOVE-G vision-language dataset; beats semantic-only localization. Failure channel they admit: repo is "actively maintained, raise problems in issues" (troubleshooting section) — no frozen breakage log. The non-AI pole inside: ranked-set retrieval + relation predicates, no weights in the decision itself.
- ArgusSceneGraph 2026-07-18 (UNVERIFIED ideas-only): the 2026 corroboration of the same shape — "VLM detects EVERY object, not just the ones named; a 3D scene graph encodes geometric grounding, qualitative-spatial relations, and semantic priors that ground affordance weighting." LLM proposes, graph disposes — same discipline as our SP43 (VLM proposal + engine repair).
- SpatialScene3D 2026-05-26 (UNVERIFIED ideas-only): the QA-gate shape. `qa_supervisor.py@668ba10` (20KB, full text read): (a) thresholds are DATA (`THRESHOLDS` dict: psnr_pass 25.0/warn 18.0, ssim_pass 0.80, lpips_pass 0.20, semantic_pass 0.50/warn 0.20, mask coverage 0.98, confidence 0.40 — each with a documented why); (b) each stage returns (verdict, reason, evidence) with UNKNOWN when its metric JSON is missing (never a crash on absent data); (c) `_worst` combines (any FAIL→FAIL, else any WARNING→WARNING, else PASS) and maps to RELEASE / RELEASE WITH LIMITATIONS / DO NOT RELEASE; (d) per-label evidence names SPECIFIC failing classes (smallest-3D-classes = coverage gaps, lowest-confidence = unreliable detections, ≥20-mask meaningfulness floor); (e) ONE bounded model call (temperature 0.2, max 900 tokens) reasons ONLY over the gate numbers ("cite real numbers, do not invent metrics") to name the dominant weakness + root cause + 2-3 class-specific next actions; (f) graceful degrade: no key → deterministic gate still runs, saved diagnosis reused with its original date labelled, report stays honest.
