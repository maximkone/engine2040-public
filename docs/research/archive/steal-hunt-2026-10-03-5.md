  adapted with attribution; reimplement shape in integers regardless, never
  vendor TS bytes into the tick.
- What it does: HOW THEY HANDLE it — every joint motor carries two numbers and
  one state. Frequency in Hz with a sim-relative bound (valid range
  `(0, 0.5 x simulation frequency]`; at 60 Hz physics, 20 Hz is stiff, 2 Hz is
  soft — stiffness is named against the step, never absolute). Damping ratio
  with named regimes (0 = oscillates forever, 1 = critical, >1 = overdamped).
  `MotorState.OFF` (inactive) / `VELOCITY` (drives to target velocity) /
  `POSITION` (drives to target position using spring) — the state, not a flag
  soup, decides which target the spring tracks. The floating character
  controller (`kcc.ts`) is the consumer that proves the discipline at character
  scale. What they test: `tst/` vitest suite + bench dir (inventory only).
  What they cut: determinism/replay (float TS, no digest — our non-negotiable,
  added in the spike).

  drive table beside the frozen weight path) + `ragdoll_tape.rs:12-15` (tape
  reuses the same API list; no second harness). Existing files only.
- Fixes: Bodies active-ragdoll leg (`plan/body-and-break.md` BX Tier A "any AI
  able to author and balance it through typed verbs" needs drives verbs can
