## CARD 1 — cone-segment spot shafts against froxel transmittance + temporal shafts filter + half-res depth composite

- Source: `Siroko/kansei@e0bbb43582fff4e9706b086b20be33c49eab3a90`
  (default-branch HEAD at read) — `rust/kansei-core/src/shaders/volumetric_fog_shafts.wgsl`
  (blob `d638232a…`, read live 2026-10-03 via GitHub API) + `LICENSE` (blob `c33507a8…`).
  DISCOVERED.md:101 already cites this repo but ONLY for `taa_resolve.wgsl` — the volumetric
  trio (inject/shafts/composite) was never opened here.
- License: **MIT** (© 2024 Felix Martinez, full text read live) — reimplement shape only,
  zero bytes vendored, attribution in the file header.
- What it does — HOW THEY HANDLE it: (a) the froxel grid holds the OTHER light + the medium,
  so shafts never re-march what injection already lit: each sample reads front-transmittance
  from the accumulated 3D texture (`shaftAccumTex` `.a` at the sample's slice `w`);
  (b) each view ray is cut to the analytic ray-vs-sphere-vs-cone segment
  (`shaftConeSegment`: sphere range quadratic, apex half-space, cone quadratic with degenerate
  `qa≈0`/`qb≈0` branches all handled — no marching empty air); (c) `steps` jittered samples
  over THAT segment only take local height-fog density (`baseDensity * exp(-falloff * h)` +
  `windOffset`), per-light shadow-map visibility (`textureSampleCompareLevel`, skipped when
  `visibility <= 0`), inverse-square clamped by `sourceRadius` (never singular), and
  Henyey-Greenstein phase on `dot(rd, s.toLight)`; (d) shafts render at HALF res taking the
  front-most depth of each 2x2 quad, then a dedicated temporal filter
  (`volumetric_fog_shafts_temporal.wgsl`, listed) + depth-aware upsample in
  `volumetric_fog_composite.wgsl` (`scene * transmittance + in-scatter`); jitter is
  frame-cycled (`frame % 64 * 0.618034` golden-ratio + per-texel IGN). What they cut: spots
  with `volumetricScale <= 0` skip entirely; samples with `media.density <= 0` skip before any
  shadow tap; output clamped (`min(scatter, 60000)`).
- Home (existing file): `crates/render/src/fog.rs` (shaft-march beside `compile_fog_for_forward`,
  RL7/RL9 frozen) + `present.rs` composite seam; new `volumetric.rs` only as the VX1/VX8
  implementation file the plan already names (`render-2040.md:97`).
- Fixes: Look — VX8 torch shafts + VX1 froxel fog (the 250-torch arena's god-rays through
  gate arches and colonnade shadows; RT16's re-open terms).
- Net lines: M (~200 WGSL + ~120 CPU uniforms/dispatch, reimplemented).
- Proof (proposed spike, not run): 2-spot-torch + 1-occluder arena fixture, 8 jittered steps,
  half-res + temporal vs flat RL7 fog; metric shaft-vs-occluder contrast lift + per-pass ms on
  RTX 3050 + llvmpipe parity + bytes x2. KILL if contrast lift <15% or any pass over the
  FOG 0.2 / CONTACT 0.3 bars or parity drift >0.004 or any tick-byte drift.
- Effort/risk: M effort; risk is bar overrun (half-res + segment-only + temporal is exactly
  their answer to it) and shadow-atlas coupling (reuse RL1 cascade binds, never a second
  shadow truth). Plan prefix: VX (VX8 leg, feeds VX1). Moves FOCUS Now pillar 1
  look-live-on-GPU toward A4; EMPIRE proof-and-pull.
