## CARD 1 — TAKE — `BreakableJoint`: tensile/shear/torsional thresholds + Miner's-rule damage (Apache-2.0)

- Source: `cool-japan/oxiphysics@fa896eb5c93b64f31a7ce6d93ad43cdbc0201829`
  `crates/oxiphysics-rigid/src/fracture_rigid.rs` (`BreakableJoint::apply_force`
  ~L150: axis projection splits force into tensile | shear, moment about axis =
  torsion; three thresholds, `JointState::{Intact,BrokenTensile,BrokenShear,
  BrokenTorsional}`; sub-threshold hits accumulate `damage` by quadratic sum
  `(d_t²+d_s²+d_t²)^½ × 0.01` capped at 1.0, then break; `released_energy() =
  fracture_energy × area`; `reset()`; all `[f64; 3]` arrays, no linalg dep).
  Sibling types in the same file (not carded, context): `FragmentSystem`,
  `ImpactFracture` (impulse Voronoi), `CrackPropagation` (LEFM + crack arrest),
  `DebrisSimulation` (secondary impacts), `ExplosionModel` (Gurney).
  License: **Apache-2.0** (LICENSE body + `Copyright 2026 COOLJAPAN OU` appendix
  read live 2026-10-02; file carries `SPDX-License-Identifier: Apache-2.0`).
  Reimplement in integers/Q16, never their f64.
- What it does: HOW THEY HANDLE it — a joint is three independent failure axes
  with named break states (tells you HOW it broke, not just that it did), plus a
  fatigue path so repeated sub-threshold hits eventually fail it; energy release
  scales with joint area so big ties throw bigger consequences. What they cut: no
  plasticity, no per-axis damage memory (single scalar), thermal/creep absent.
  What their tests say: file holds `#[cfg(test)]` cases beside the types (wieved
  in listing; bodies unread — cap — so their proof is their claim).
- Home: `crates/destruction/src/bonded.rs:1` (bond collections with strain gain
  a per-bond direction triple + damage scalar beside the strain) — the plan's
  missing `structure.rs` load-path joints and `tie.rs` cuttable ropes hang off
  this shape.
- Fixes: Bodies — BX Tier B collapse-by-load-path + severable ties (which bond
  broke, in which direction, from a tick-stamped integer event). Core line: Bodies.
- Net lines: ~110 (axis-split failure eval over our bond graph in Q16 + damage
  scalar + three break states folded into the existing break event + 4 tests:
  tensile/shear/torsion isolation + fatigue-to-fail).
- Spike: fixture = bonded wall course with one overloaded tie; metric = break
  tick + break direction identical x2 runs and x2 PCs. Beat: today's single
  impulse-per-mass gate (no direction, no fatigue). Kill: any rerun divergence,
