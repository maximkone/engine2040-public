# GH-W — delivering a game to a browser (powerups wave, 2026-10-21)

Lane: WebGPU caps and fallbacks, asset streaming and lazy loading, compression and bundling
for the web, worker and offscreen rendering, and the size budget that keeps the whole game
small. Read-only lane: one file, nothing committed. Every donor file and licence was read
live on 2026-10-21 (GitHub contents API, GitHub code search, raw source, or a live HTTP
request), and the tree was grepped before anything was called missing. Row ids: `A*` are the
gaps in `docs/plan/finish-line.md`, `WEB*` are in `docs/SPRINT-22-web-realism.md`, `PW*` are
in `docs/SPRINT-28-powerups.md`.

**Answer.** The browser half of engine2040 is mostly built, so the donors that pay are the
small ones that close the last mile: the load (a deadline so the page never spins forever, a
per-item queue so it can say what it is waiting for, a byte counter so the bar has a
denominator), the byte budget (the shipped module sits at 97.7% of its cap, and the gate
measures a brotli sum while the live host serves gzip), and the packaging (the data outside
the binary, the module stripped, the memory ceiling declared). Two of the five sub-areas turned
out to be already closed by our own tree, and that is worth more than another donor: the
WebGL2 fallback question is answered (a WebGL2 fallback is impossible for our renderer —
`crates/web/src/limits.rs:204`, our own test, says the WebGL2 downlevel set has fewer storage
buffers per stage than the shadow cluster needs), and the size gate already exists and
already fails over a bar (`tools/web-budget.mjs`). What
is left is wiring, not a new engine: the web half of the load queue (A2 / WEB6), the wasm
byte budget (WEB11), the compressed-format pick (PW40) and the render worker (the hunt's
wild idea #4). I measured the live site while I was there: the last recorded build's module
was 4,150,422 B raw, 97.7% of the 4,250,000 B cap in `tools/web-budget.json` (the PW37 board
row), and the deployed `engine_bg.wasm` is 1,201,347 B on the wire with
`content-encoding: gzip` (HEAD `https://maximkone.github.io/engine2040-public/engine_bg.wasm`,
2026-10-21, `cache-control: max-age=600`, an ETag is present), so a visitor pays 1.2 MB, not
4.15 MB — the raw cap is the one that bites. Two things have no donor today and are recorded
as such: range-request asset streaming (three.js' KTX2Loader has no Range support, read
today) and a precache service worker (the Workbox repo 404s today, verified three ways).
