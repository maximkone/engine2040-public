# GH-L — the look lane: toon/CEL, inverted hull, rim, grading and stylised passes

Lane question: which open-source GitHub repos hold production-grade techniques for TOON/CEL shading, inverted-hull outlines, rim light, colour grading and LUTs, stylised lighting and screen-space stylisation that a wgpu forward renderer can port, for a deliberate 2005 Korean MMO look (chunky low-poly, hard painted light, strong dark palette with a bright trim, readable at 30 m)?

**Answer.** The strongest donor found is `togechiyo/MMD_modoki` (MIT, 147 stars, pushed 2026-10-21, read live) — it is a WebGPU/MikuMikuDance renderer, and MMD *is* the ancestor of the 2005 Korean MMO look: its `MMD Standard` toon preset is a hard rule we can read line by line — the shadow colour is **one texel** of the toon texture (fetched with `textureLoad`, no filtering), and the light/dark boundary is the product of a self-shadow mask and an occlusion mask. It also carries an inverted-hull outline that holds a **constant width in pixels** (the offset is divided by the viewport and multiplied by `clip.w`), which is the one thing the already-mined `komadori/bevy_mod_outline` row cannot do without a cooked per-vertex outline normal. Everything else in the lane is a smaller, cheaper steal: `BabylonJS/Babylon.js` (Apache-2.0, 26k stars) ships **WGSL** for a three-band colour curve (shadows/midtones/highlights), a 3D-LUT grade, a dither and a fresnel rim term; `storytold/effectcraft` (Apache-2.0 OR MIT, 7.6k stars) ships a **tetrahedral 3D-LUT interpolation in WGSL** plus a per-pixel posterise/threshold path that mirrors its CPU effect operation for operation; `water-rs/waterui` (Apache-2.0 OR MIT, 523 stars) ships an antialiased dot/line halftone in WGSL; `renzora/engine` (Apache-2.0 OR MIT, 381 stars) ships a Bayer-4x4 dithered level-quantise; `DoubleStyx/Renderide` (MIT) ships a stepped wrapped-Lambert + stepped Blinn-Phong toon BRDF in one forward pass; `milos-agathon/forge3d` (MIT, 817 stars) ships a cel BRDF whose **shadow side returns the rim colour instead of black** — the "bright trim on a dark palette" in eight lines. `mrdoob/three.js` OutlinePass (depth-buffer Sobel) is the one RESEARCH-ONLY row: it is the cheap fallback for the potato tier, but a second screen-space outline on top of the already-mined jump-flood row is not a new row.

## Rejections

- `BabylonJS/Babylon.js` `packages/dev/core/src/ShadersWGSL/outline.vertex.fx` — classic object-space `position + normal * offset` inverted hull: same idea as the already-mined `komadori/bevy_mod_outline` row, and worse for us (width shrinks with distance). Row 2 is the better variant.
- `BabylonJS/Babylon.js` `packages/dev/core/src/Layers/highlightLayer.ts` — screen-space glow outline: a third screen-space outline, same reason as row 12.
- `BabylonJS/Babylon.js` `packages/dev/core/src/Materials/colorCurves.ts` — the CPU side that packs the curve; we can write our own four floats, and the WGSL half is row 4.
- `AcademySoftwareFoundation/OpenColorIO` `src/OpenColorIO/Lut3DOp.cpp` — **404 today (2026-10-21)**; the op moved to `src/OpenColorIO/ops/lut3d/` (tree listing OBSERVED). The tetrahedral rule is cited from the CPU file and the WGSL port target is row 3.
- `renzora/engine` `assets/shaders/post_process/color_grading.wgsl` — brightness / contrast / saturation / gamma / temperature / tint: our tree already has contrast + saturation in `post.rs` `GradeConfig`; not a gap.
- `renzora/engine` `assets/shaders/post_process/outline.wgsl` — 8-tap Sobel on *colour* luminance: it outlines texture detail, not silhouettes; the depth Sobel (row 12) is the honest one.
- `renzora/engine` `assets/shaders/post_process/halftone.wgsl` — dot halftone with a `512/dot_size` uv approximation; waterui's version (row 7) is antialiased and area-proportional, so this one loses.
- `guilhermebo0510/anigo` (`crates/anigo-renderer/shaders/inverted_hull.wgsl`) — 0 stars, **no LICENSE file**: no licence means no port.
- `nuts-rice/shady_shaders` (`src/shaders/outline.wgsl`) — 1 star, **no LICENSE detected**: no port.
- `Unity-Technologies/Graphics` (MIT) — has a real URP toon shading model and would answer row 1/6, but Unity is on this wave's do-not-repeat list, so it is not ranked; noted so nobody re-mines it.
- `Unity-Technologies/PostProcessing` (MIT) — has a Posterize effect, same reason (Unity excluded).
- `Unreal`, `Godot`, `O3DE`, `Flax`, `Stride`, `Filament` — excluded by the wave rules (and proprietary for Unreal/Unity anyway).
- `alertform/ue5-anime-renderer` — already rejected on 2026-10-21 (hunt-2026-10-21/06-outside-hunt.md:87): anime look, our bar is a Roman legionary.
