# research/ — one screen: every dated folder, what it feeds, and what is history

Read this before opening a dated folder. One folder per hunt or wave; each holds
its own evidence. Nothing here is a contract: plans say how, the board says what
is open (`docs/SPRINT.md`), `docs/FOCUS.md` says in what order.

**Status keys.** `LIVE` = feeds open rows or a current gap wave; read it before
you write a row. `EVIDENCE` = cited by a plan, book page or tool; read the cited
file only. `HISTORY` = its wave is closed and the board holds what it proposed;
read it as history, do not cite it in a new row.

A new folder gets one line here in the same commit. Never move a folder without
fixing the lines below and adding one line to `../archive/INDEX.md`.
