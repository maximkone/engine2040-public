# The donor map: which donor serves which open row (hunt 2026-10-21)

The point of this file: the finish-line gap list is partly stale, and most of the
good donors land on rows that already exist. So the map is **donor -> open row**,
not "new idea -> new row". A row with a donor attached is a row with a plan.

Read a row's plan with `node tools/board-slice.mjs <ID>`, and the plan file with
`node tools/plan-atlas.mjs --row <ID>`.
