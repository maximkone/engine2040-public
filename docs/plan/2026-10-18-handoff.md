## Hard rules
1. Commit only your own paths: `git commit -F <msgfile> -- <paths>`. New file: `git add -N <file>` first, and put the `mod x;` line and `x.rs` in the SAME commit. Never `git add -A`, never rebase, amend or force-push, never revert edits you did not make, never `git clean` under `target/`. Push with `git pull --no-rebase --no-edit origin master` then `git push origin master`. Commit messages end with a Co-Authored-By line for the model you are.
2. Heavy cargo runs on GitHub: `node tools/gh-check.mjs cargo test -p <crate> [--features ..] <filter>` and `cargo clippy -p <crate> --all-targets -- -D warnings`. Game crate tests need `--features app`; endpoint needs `--features mcp`. After a change to a shared seam run the whole `cargo test -p <crate> --no-fail-fast` (the `it` test binary hides reds). The gh-check push to the mirror sometimes fails with "unable to write file ... pack": just run it again.
3. Before every commit: `cargo fmt` on your files, `node tools/rust-quality.mjs --owned`, `node tools/workspace-check.mjs` (no FAIL from your files). New pub items need rustdoc. ASCII in new files.
4. Tick a board row only when a named test ran green: change `- [ ] ID` to `- [x] ID` and append ` Landed <sha7>. <test names and gh run id>.` at the END of the last line of that row. Partly done: append ` Progress 2026-10-18: <what exists, sha7, what is left>.` and leave it open. Commit the shard by path. Never tick on "looks done".
5. Do not touch `docs/EMPIRE.md`. Never delete a module that a board row names (see `docs/plan/2026-10-18-deleted-code-triage.md`). Disk is tight: never leave private `CARGO_TARGET_DIR`s behind; delete by exact path. If C: runs low, delete `target/debug/incremental/<dir>` entries older than 3 hours (not `deps/`).
