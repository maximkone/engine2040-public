# Book gaps vs engine2040 (2026-10-12)

Owner ask 2026-10-12: we read the engine books, review the gaps in the plans, "for engine2040 i want it properly".
Eight reviews (Gregory GEA ch1-16, Lengyel FGED vol 2 rendering, Finska Modern Game Testing) were merged here and deduped.
Written by center as a document only. The board (`docs/SPRINT.md`), `FOCUS.md`, `AGENTS.md` and the plan rows are the loop's:
nothing here ticks, unticks or edits them. Every row below that says "HAS" or "MISSING" came from a file read or a search;
the 10+ claims I re-checked by hand are listed in section 7. Cites are `file:line` at 2026-10-12. Items marked (by reading)
were not run.

## 1. Verdict

engine2040 is strong where a deterministic engine must be: the fixed 60 Hz integer step, the ECS with generation handles,
the golden hash, bug bundles, the combat and AI depth, the animation set (state machine, IK, foot lock, ragdoll code). The
big problem is not missing ideas. It is code that exists and nothing calls it. The sun shadow map is drawn every frame and
never read, GTAO is computed and thrown away, bloom, TAA, particles and decals have no draw, captures are made with the sky
off, the P2P rollback has no caller, the nav flow fields never reach the arena, the stream queue never reaches the game.
So the picture the window shows (ACES, fog, one light, IBL ambient) is far below the numbers the code base seems to hold,
and the per-pass timing rows lie because they time bind probes. Second theme: the plans disagree with the disk and with
each other (two finish files, "will not build" vs open rows, rows ticked and dropped, rows saying a file does not exist).
Third: the shipped game binary builds no Rapier bodies and the live netcode is server-authoritative, so the plan words
"ragdolls a fighter" and "rollback netcode" describe paths the player does not run. Fix order: wire, then measure honestly,
then add. Section 6 lists the decisions only the engine2040 lead can take.

## 3. The render order (Gregory ch10 and Lengyel agree)

Rule: nothing counts until a window or capture frame shows it. Step 0 comes first because the proof depends on it.

0. Honest per-pass time. Sky, layers, particles, decals, ibl, fog and gtao time bind-probe copies (`sky.rs:837-841`,
   `particles_gpu.rs:767/1026-1032`, `decals.rs:984/1280-1286`), so `0.000 ms` is not evidence. Time the real draw.
   Paths: `crates/render/src/backend.rs` (BENCH_PASSES), `present/gpu_present/submit.rs`. Proof: ARENA `arena per-pass:` line
   lists each pass with a draw behind it.
1. Sample the sun depth map (W1). Add binding 13 depth + 14 comparison sampler, 3x3 or 5-tap PCF, slope-scaled bias
   (`sun_shadow.rs:156` is `DepthBiasState::default()`), call `snap_texel` (W8), overlap blend between cascades later
   (`forward.wgsl:401-408` has hard bands). Rows EG11/EG11b, RL27. Proof: `Select-String crates\render\src\shaders\forward.wgsl
   -Pattern "textureSampleCompare"` hits; ARENA per-pass shadow ms > 0; capture shows fighter shadows on sand (EG8 on vs off).
2. Fix capture sky (W6). Paths: `present/gpu_present/submit.rs:653,677`, `live.rs:345`. Proof: `Select-String
   present\gpu_present\*.rs -Pattern "encode_forward\("` shows no `false`; look report sky frames 5/5 (campaign: 0/5 now).
3. Bloom before ACES (W3). Paths: `post.rs`, `submit.rs` (`encode_blit`), `shaders/blit.wgsl`. Rows LF4/RP1. Proof: ARENA
   per-pass bloom ms > 0 with a capture where torch or sun glint has a halo.
4. Ambient-only AO from a prepass (W2). Add a depth prepass (`submit.rs:410-419` has none; the draw loop
   `:505-516` is unsorted, caller order) (corrected 2026-10-12: this said "also sorts by material"; rg finds no sort there, see BOOK-GAPS-2), run GTAO on it, multiply the ambient term only in `forward.wgsl:415`, delete the whole-HDR multiply at
   `blit.wgsl:50`. Rows LF3, GX5 (see section 5). Proof: ARENA gtao ms > 0; capture diff on vs off changes shadow-side pixels
   and leaves sun-lit pixels equal.
5. Particles and decals (W5). Paths: `particles_gpu.rs`, `decals.rs`, one shader each. Decals draw in scene before TAA
   (`render-look.md:151-152` puts them after). Rows RP2/RP3/LF6/LF7. Proof: capture of a hit shows dust and a blood decal.
6. Normal maps and torch lights (W9). Forward binds only `base_map` (`forward.wgsl:74`), uses the raw vertex normal (:410),
   one light. Rows LF8, VS7. Proof: `Select-String forward.wgsl -Pattern "texture_2d<"` shows normal and roughness maps; a
   night capture shows torch light on a wall.
7. Anti-aliasing (W4). MSAA first (`submit.rs:129`), TAA with a motion target after. Rows LF5, RP4, EG13. Proof:
   `sample_count` 4 in the forward target; silhouette-flicker score down on a 300-frame run.

Later (no row or Tier C): height fog as a ray integral (`fog.rs:424` samples one height), sun shafts and torch halos
(`render-look.md:95` "volumetrics", no row), reversed-Z, shadow-caster cull, Hi-Z, motion blur, skin scatter (LF8).
