# Steals: open steals that land on a finish bar

The scout seat (`target/queue/standing/researcher-open-hunt.md`) appends one `open` line per steal under `## Steals`; the builder that lands it marks it `landed <sha>` in the landing commit. Center's size check FAILs a 4th open line per bar and an open line older than 7 days. Not a plan: it holds lines, not rows.

Line format: `YYYY-MM-DD | <bar id> | donor repo@commit, arXiv id or our-repo tool | license | our/file | open`, then one indented line: `what to change, and the number it moves: <before> -> <target>`.

On 2026-10-10 the open list was capped at 3 per part (steal-land --gate). Lines over the cap, the landed lines and the one donor already in code moved to docs/archive/2026-10-10/plans/steals-closed.md.
