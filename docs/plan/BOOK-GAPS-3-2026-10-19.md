## 4. R1: the geo Rust/C++ struct pair has no layout assert (NB1)

Doc: Nomicon, "Calling foreign functions" and the `repr(C)` layout table:
the Rust compiler cannot check a foreign declaration, so a field that is
added, reordered or re-typed shifts every field the C side reads.

Disk: `crates/geo/src/uv.rs:83` `Params` (20 fields), `:109` `Info` (6),
`extern "C"` at `:118-137`; the C++ mirror
`crates/geo/vendor/xatlas_shim.cpp:12` `GeoXatlasParams`, `:35`
`GeoXatlasInfo`; `rg "static_assert" xatlas_shim.cpp` = 0;
`rg "size_of|offset_of" uv.rs` = 0. `tools/miri-sites.json` skips the file
because the C++ library is foreign code Miri cannot execute. The only net is
the real-FFI tests at `uv.rs:529` and `:707`, which would come back subtly
wrong rather than fail loudly if two same-width fields swap.

Packet: `const _: () = assert!(size_of::<ffi::Params>() == N);` plus one
`offset_of!` per field, the same for `Info`; matching `static_assert` in the
shim (the vendored xatlas pins its own pairs at `vendor/xatlas/xatlas.cpp:9937-9944`).

Proof: `rg -n "size_of|offset_of" crates/geo/src/uv.rs` hits;
`cargo test -p engine-geo --lib` green; the real-FFI tests stay green.
