# E86 receipt: target/debug capped by moving it to the quarantine

Date: 2026-10-22. Owner of the change: the E86 row.

The 2026-10-20 receipt moved the debug cache by hand and left one thing open:
"`tools/clean.mjs --auto --include-debug` hard-deletes with `rmSync`; it needs
the quarantine behaviour before it may run on this repo." That is now the tool's
behaviour, so the row's own command is safe to run.

## What the tool does now

`tools/clean.mjs` never deletes. A path it removes is MOVED to
`C:\_quarantine\<date>\` and one `MOVES.tsv` row records the move (date, from,
to, reason). A live `cargo` or `rustc` makes the tool refuse (exit 3) and change
nothing, so a build is never pulled out from under itself.

## The dry run before

`node tools/clean.mjs --dry-run --include-debug` in `C:\engine2040`:

```
WOULD target\tmp 0.00 GB
WOULD target\debug 21.34 GB
WOULD reclaim 21.34 GB across 2 path(s), 0 moved to C:\_quarantine\2026-10-22
```

## What moved

`node tools/clean.mjs --auto --include-debug` (no cargo or rustc running):

```
trash target\tmp 0.00 GB
MOVED target\tmp -> C:\_quarantine\2026-10-22\target-tmp
deep-debug target\debug 21.34 GB
MOVED target\debug -> C:\_quarantine\2026-10-22\target-debug
MOVED 21.34 GB across 2 path(s), 2 moved to C:\_quarantine\2026-10-22
MOVES.tsv C:\_quarantine\2026-10-22\MOVES.tsv
```

Two rows in `C:\_quarantine\2026-10-22\MOVES.tsv`:

```
2026-10-22	C:\engine2040\target\tmp	C:\_quarantine\2026-10-22\target-tmp	clean.mjs trash: target\tmp moved, not deleted (owner rule: never a hard delete)
2026-10-22	C:\engine2040\target\debug	C:\_quarantine\2026-10-22\target-debug	clean.mjs deep-debug: target\debug moved, not deleted (owner rule: never a hard delete)
```

The debug cache in the quarantine: 49,450 files, 21,341,494,475 bytes (19.88 GiB).
Nothing was deleted, so the bytes sit on the same volume: C: free went
39.71 GB -> 34.55 GB (other builds ran meanwhile). Only the owner trims the
quarantine.
