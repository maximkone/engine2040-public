## Command

```text
node tools/ship-run.mjs --proof target/release/engine2040.exe \
  --arena target/e22/ship-arena/arena.exe \
  --log target/e22/ship-run-gpu.txt
```

The arena is the mirror's clean-folder artifact. The proof binary is the local
release `target/release/engine2040.exe`; the mirror's own ship-run receipt
already proved its proof binary, and this run only adds the frame leg that the
runner cannot draw.
