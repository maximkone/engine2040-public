# skills/

Task skills, one folder per job.
Each folder holds one `SKILL.md`.
Open `skills/SKILLS.md` first for the agent to skill map.
Then read one skill, e.g. `skills/engine-orchestrate/SKILL.md`.
`skills/opencode-loop/SKILL.md` applies to every turn.
Agents live in `.opencode/agents/`.
Keep edits small and keep `skills/SKILLS.md` in sync.
