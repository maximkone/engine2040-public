# Tested pairs: the cargo-book rules, each replayed with real cargo

Made from pairs.json. Do not edit this file by hand.
Every pair runs with real cargo 1.97.1 in its own fresh scratch directory under $TEMP/opencode with no network (see scripts/cargo_book.py). `good` prints the output shown; `bad` fails with the real error named.

## Start and lock

### cb-p01

bad:

good:
