# CT9 map kits (Tier C) — `content/maps/`

Original authored kit, CC0-1.0, engine2040 CT9 lane. No donor bytes: every
file below is generated by `content/maps/tools/gen.mjs` (node stdlib only, deterministic)
and proven by `proof/` through the engine's own lanes (CT2 mesh cook, A2
texture cook, AS1 bundle, SP1 spatial gate). Same pipeline as the CT8 arena
kit, extended with one validity probe placement per map. Nothing outside
`content/maps/` is touched by this packet.

## Conventions (from `docs/plan/content.md`)

One mesh per solid part, every box subdivided n=4 (CT8/CT9 repair lesson:
n=2 slivers collapse to empty LODs in the greedy CT2 pass). `COL_` meshes
are collision-only proxies (never rendered). `FRAC_block_*` nodes on the
siege wall collect 6 DX1 chunks, faces offset 0.02 proud so they never
z-fight the wall face. `SOCKET_muzzle` marks the ballista aim anchor (WD10).
Materials: one PBR set per asset, ≤ 4 per character by construction
(static kit: 1).

## Budgets (proven in `report.json`)

- Props ≤ 5k tris LOD0: worst asset palisade 3264, total kit 25,968.
- Albedo textures ≤ 512, data ≤ 256, power-of-two, mip chain to 1×1 (A2 rules).
- LOD chains monotonic, non-empty, meeting `LOD_RATIOS` targets; every hull
  contains its mesh; cook identical twice; bundle (AS1) identical twice,
  loads via `BundleLoader` (the WIN1/ED1 loader), corrupt bytes refused.
- Spatial `run()` over each placed probe: 0 findings, verdict clean.

## Reproduce

- `node tools/gen.mjs` (from this dir) — regenerates byte-identical files.
- `cargo run --offline` (from `proof/`) — re-proves; exit 0 + GREEN.

Consumer: WD2 ludus map loads the AS1 bundle (`maps/*` entries); proven here
by headless import test + the exact startup loader + the 8-actor ludus
validity probe. No window GUI runs in this environment (no display server),
stated, not hidden.
