## Conventions (from `docs/plan/content.md`)

One mesh per solid part (merged disjoint boxes degenerate to empty LODs in
the greedy CT2 pass — found and fixed in this packet). `COL_` meshes are
collision-only proxies (never rendered). `FRAC_panel_*` nodes on the crate
collect 6 DX1 chunks. `SOCKET_flame` marks the torch flame anchor. Materials:
one PBR set per asset (baseColor/metallic/roughness factors + albedo and
flat-normal texture refs), ≤ 4 per character by construction (static kit: 1).

## Budgets (proven in `report.json`)

- Props ≤ 5k tris LOD0: worst asset crate 1536, total kit 7472.
- Textures ≤ 2k, power-of-two, mip chain to 1×1 (A2 rules).
- LOD chains monotonic, non-empty, meeting `LOD_RATIOS` targets; every hull
  contains its mesh; cook identical twice; bundle (AS1) identical twice,
  loads via `BundleLoader` (the WIN1/ED1 loader), corrupt bytes refused.
- Spatial `run()` over the placed kit: 0 findings, verdict clean.

## Reproduce

- `node tools/gen.mjs` (from this dir) — regenerates byte-identical files.
- `cargo run --offline -- ..` (from `proof/`) — re-proves; exit 0 + GREEN.

Consumer: window arena loads the AS1 bundle (`arena/*` entries); proven here
by headless import test + the exact startup loader. No window GUI runs in
this environment (no display server), stated, not hidden.
