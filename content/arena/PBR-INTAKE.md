# CT74 PBR/HDRI intake commit-gate

Row: CT74 content. Tier A. Size S. Owns `content/arena/PBR-INTAKE.md`.
Intake bytes stay frozen: nothing here adds, moves or deletes a file.
Needs: CT8 (arena kit), CT46 (provenance matrix). Consumers: CT45, CT57.

## Gate rule

A shipped file under `content/arena/` must carry a provenance row (URL + SPDX +
author + SHA, or the AI chain) in the CT46 matrix (`content/PROVENANCE-AUDIT.md`,
generated by `node tools/provenance-audit.mjs`). A file with no row is refused,
and the refusal names the file and the reason. This matches the Rust check in
`crates/assets/src/provenance.rs` (`check_record`). Raw inputs and receipts are
not shipped assets: they are listed as trees outside the matrix.
