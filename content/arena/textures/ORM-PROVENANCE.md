## 1. Authored ORM set (`textures/*_orm.png`, new)

Grayscale roughness maps cannot bind as `metallicRoughnessTexture` (the B
channel would read ~0.9 = mirror stone/sand/wood/cloth — the standing note in
every prior CT26 provenance file). The fix is an authored
occlusion-roughness-metalness PNG per family: R=255 (occlusion n/a, the
engine reads occlusion from its own slot), G=roughness, B=metalness
(0 = dielectric). Generated by a deterministic stdlib-only script (flat
256x256 RGBA, zlib level 9, temp, not in git); re-running it on pristine
HEAD copies reproduces every SHA below exactly.
