# content

Game data for the arena build.
Open content/SHIP-SET.md first for what ships.
content/arena/ holds arena textures and models.
content/fighters/ holds fighter data and atlases.
content/maps/ holds maps and traversal hints.
content/sprites/ holds 2D sprites and licenses.
content/audio/ holds sound data.
content/locomotion/ holds clips and sidecars.
content/design/ holds designer rows files, see docs/design/FORMAT.md; change a number there and the game changes with no Rust edit.
content/kit-common.mjs is the shared kit helper.
Keep imports cooked; do not hand-edit generated files.
